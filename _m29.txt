修 UI 冲突：面板改为点击穿透 + 位置可调 + 从原生熔炉上撤下

## 用户反馈
「可以正常打开，但是和游戏的内容框冲突，并且打开后无法关闭，无法点击，无法移动」

## 问题 1：面板吃掉了鼠标点击（严重）
原因：`EnsureRoot` 里加了 `GraphicRaycaster` + 面板 `Image` 参与射线检测
→ 面板把鼠标事件全拦了，游戏自己的关闭按钮/控件收不到点击。

**修法（三重保险）**：
* **移除 `GraphicRaycaster`** —— 我们的 UI 是纯展示，不需要接收任何点击
* 所有 `Image` 显式 `raycastTarget = false`
* Canvas 上加 `CanvasGroup { blocksRaycasts=false, interactable=false }`

→ 效果：**点击完全穿透**，游戏窗口的关闭/点击/拖动恢复正常。

## 问题 2：面板和游戏窗口重叠
新增 cfg（**热生效**，可在游戏里直接调）：
```ini
[UI模板]
面板横位置 = 420    # 面板中心相对屏幕中心的像素偏移（正=右）
面板纵位置 = 0      # 正=下
```
默认放在屏幕中心**右侧 420px**，避开居中的游戏窗口。

## 问题 3：2×2 高炉重复显示
它的窗口是 `window_furnace`，**自带完整原生界面**
（工作类型 / 配方下拉 / 燃料设置 / 进度）——
再叠一层我们的面板只会重复且冲突。→ `BuildingSpec.BlastFurnace.Ui = null`。

**通用 UI 模板的定位**（明确一下）：
* **3×3 自研高炉**（105054）：窗口借的是采集营地窗口，**没有冶炼界面** → 必须用我们的模板 ✔
* **2×2 原生高炉**（105053）：窗口自带完整界面 → **不用**我们的模板 ✔
* 判据写进注释：**建筑窗口自带功能界面时不要叠模板**
