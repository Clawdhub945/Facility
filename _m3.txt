修复新建筑的窗口：下拉被自己隐藏 + 原版方法空引用

## 用户反馈
「原版的 UI 正常了，现在你把新增的 2 所建造修一下，一样是材料取用范围，还有进度等没正常显示」

## 三个问题（本轮全部定位并修复）

### 1. 原生下拉"被填充了却看不见"
诊断（新增 `DumpDropdownChain`，打印下拉自身与各级祖先的 activeSelf/坐标）直接给出答案：
```
dp_blueprint      activeSelf=True  inHierarchy=False   ← 自己是活的，祖先被关
  fomula_item_main activeSelf=False                    ← 元凶：我把它隐藏了
    window_blacksmith
显示值=秘银矿 +10/日  选项数=4                          ← 数据侧一直是好的
```
**`fomula_item_main` 就是原生下拉的父容器** —— 我为了去掉「可使用的材料」「建造 100%」
把它的祖先一起隐藏了。教训：隐藏前必须确认目标**不是**要保留控件的祖先。
修法：从隐藏名单里移除 `fomula_item_main`（并写进代码注释 + 文档警告）。

顺带修正另一处同类错误：隐藏 `res_grid` 会连带干掉它下面的东西，
改为只隐藏它内部的格子 `icon_num` / `icon_num_1..5`。

### 2. `WindowWorkshop.ShowWindowTip` 空引用
```
System.NullReferenceException at WindowWorkshop.ShowWindowTip()
```
原因：它内部要用 `this.workshop`（`FacilityWorkshop`，制造台的工坊组件），
我们的建筑是 `FacilityGatherersHut`、**没有这个对象** → 必崩。

### 3. `WindowWorkshop.InitWorkshopOptionData` 空引用
```
at WindowWorkshop.InitWorkshopOptionData(... List<T> formula_list, FacilityWorkshop workshop ...)
at WindowWorkshop.InitDpBlueprint()
at WindowWorkshop.SetInfo(Facility facility)
```
它要制造台的 **`formula_list`（配方表）**，我们没有配方 → 传 null → 崩。
而且我们**不需要它**：下拉候选是 `NativeDropdown` 自己填的。

## 修法：新增「窗口安全护栏」`NativeWindowSafetyPatch`
当窗口属于**本 mod 建筑**时，跳过原版窗口里那些依赖工坊组件的方法：
```
WindowWorkshop.ShowWindowTip / Refresh / UpdateAlternativeFormula
WindowWorkshop.InitDpBlueprint / InitWorkshopOptionData      ← 静态方法，按名字+DeclaredOnly 找
WindowWorkFacility.ShowWindowTip
WindowWorkFacilityWithStockAdjust.ShowWindowTip
```
共 7 个。**原版窗口照旧执行**（归属判断 fail-safe，不会误伤）。

## 实测（全绿）
- 护栏挂载：`窗口安全护栏挂了 7 个方法`
- 最近 200 行日志：**无空引用** ✔
- 归属判断：`facility_guid=27249342 → 我们的`（只打一次，不刷屏）
- 原生下拉：`显示值=红宝石 +10/日  选项数=4`，按 F8 切换后 `cfg 额外产品 = 612001` ✔
- 窗口已清掉「可使用的材料」与「建造 100%」

## 新增诊断（详细模式）
- `DumpHidden(window)`：窗口一级子物体 + 所有被隐藏的物体路径
- `DumpDropdownChain(window)`：下拉自身与各级祖先的可见性 + 显示值 + 选项数
  —— 这两个是这次定位问题的关键，以后 UI 出问题先用它们。
