UI 模板：加独立 Canvas 置顶 + 修 ShowWindowTip 空引用

## 用户反馈
「并没有看到色方块」+ 报错：
```
System.NullReferenceException at WindowGatherersHut.ShowWindowTip()
```

## 本轮改动
### 1. 修空引用
`WindowGatherersHut.ShowWindowTip` 加进 `NativeWindowSafetyPatch` 护栏
（我们的建筑借 `window_gatherers_hut` 时它要的字段没绑上 → 抛空引用）。

### 2. 面板加**独立 Canvas**（uGUI 唯一可靠的置顶方式）
```csharp
var cv = root.AddComponent<Canvas>();
cv.overrideSorting = true;
cv.sortingOrder = 30000;          // 远高于游戏 UI
root.AddComponent<GraphicRaycaster>();
```
**为什么必须这样**：游戏 UI 是**自绘批渲染**（`batch_sprite_renderer_*`）画的，
我们的面板是标准 uGUI —— 两者在不同渲染体系里，
只改同级顺序（`SetAsLastSibling`）**压不住**游戏自绘的 UI。
用户提供的 UnityExplorer 层级图证实：
`facility_ui_template` **确实存在于窗口下**（物体是活的），
但屏幕上被游戏 UI 盖住 → 看不见。
