【根因定位】UI 模板/标定块不可见 = 窗口根 rect 高度为 0，子物体被算成 0 高

## 决定性日志
```
标定红块位置已热更新：anchoredPosition=(339,-4600) → 屏幕像素≈(1,941)
                      （中心点；尺寸 260×0，Canvas 换算 0.9）
```
**尺寸 260×0** —— 物体在、位置对，但**高度是 0**，所以屏幕上什么都看不到。

## 根因链
1. 窗口根 `window_gatherers_hut` 的 `rect` 是 **550×0**（高度 0）
   —— 实测 `DumpCoordSys` 输出，游戏自己的子控件（`title_area` 等）也全是 `550×0`
2. 所以任何 **`anchorMin=0 / anchorMax=1` 的拉伸子物体 → 高度 0**
3. 任何"拿父 rect 推算尺寸"的写法 → 也是 0
4. 游戏 UI 是**自绘批渲染**画的（不依赖 uGUI 布局），所以**不存在"窗口可视矩形"可当参照**
   —— 这才是前面所有"用锚点推算位置"尝试失败的真正原因

## 修法
* 标定红块：**直接把 Image 挂在根物体上**，尺寸用**显式 `sizeDelta=(260,150)`**，
  不再建子物体、不用拉伸
* 面板模板：根用**中心锚点 + 明确尺寸**；子物体才可以用拉伸（父已给明确尺寸时是安全的）
* 保险：`AutoEnsure` 检测到红块 **高度 < 1px** 就销毁重建
  （避免"修复前建的旧物体"一直不可见）

## 实测对应关系（用于标定）
```
anchoredPosition (0, 0)      → 屏幕 (0, 900)    = 左下角
anchoredPosition (400,-400)  → 屏幕 (4, 904)
→ 屏幕x ≈ 0.9 × X ；屏幕y ≈ 900 + 0.1 × Y（Y 系数很小，所以要大幅调整）
```
