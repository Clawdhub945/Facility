实验建筑换骨架：mine → trading_desk（修「只能建在山体上」）

## 实验结果（用户实测反馈）
**机制侧全部通过**：
- 3×3 占地 + `FacilityFurnace` 机制 + `window_furnace` 窗口 **能共存**
- 窗口正常显示熔炉那套 UI：焚烧回收物品列表（物品名称/库存/计划库存）、
  三个复选框（禁止焚烧本地居民尸体 / 杂工协助搬运 / 隐藏通常无需回收的物品）、
  材料取用范围、**「设置燃料类型」按钮**、工人数
- 说明「高炉烧煤（煤=燃料）」这条路**可行**

**唯一问题**：`mine`（矿井）预制体**自带建造地形限制** —— 只能建在山体上。
这是预制体本身的行为（build.json 里**没有**地形字段，数据改不了），不是熔炉机制的问题。

## 修法
骨架换成 **`trading_desk`（交易台）**：
- 原生 **3×3**、平地上可建、build.json 里**无任何限制字段**
- 图标暂借 `ui_103004`、on_map 用 `trading_desk_0`（保证菜单与地图不白块）

## 对比：(3×3 候选骨架一览，供以后选型)
| prefab | 建筑 | 限制 |
|---|---|---|
| `trading_desk` | 交易台 | **无** ✔ 本次选用 |
| `roulette_wheel` | 幸运轮盘 | 仅 can_exceed_worker_max_limit |
| `mine` | 矿井 | **只能建在山体上** ✗ |
| `mine_abandoned` | 废弃矿井 | res_range 2 |
| `castle1` / `tribe1` | 小城堡/小部落 | res_range 3 |
| `ancient_tomb` | 古墓 | 无 |

## 结论（工业 mod 的技术选型）
高炉可以做成 **3×3 + 真烧煤（燃料机制）**，骨架用 `trading_desk` 这类"无限制的 3×3"。
下一步可以做：煤+铁锭的燃料/配方配置、钢物品、钢制工具配方。
