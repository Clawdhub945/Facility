紧急修复：面板不显示（我上一轮引入的严重 bug）

## 用户反馈
「打开 3×3 高炉后没有出现UI！！」

## 根因（我引入的）
上一轮加"关闭按钮"时引入了 `_userClosed` 标记，配套的复位逻辑写错了：
```csharp
// 错误写法
if (_userClosed && facility.gameObject.activeInHierarchy) return;
```
窗口关闭时**设施对象仍然活跃**（它在地图上，不是窗口），
所以"重新开窗"检测不到 → `_userClosed` **永远不复位** → **面板从此再也不显示**。

另外两个也试过但同样错的方案（记录备查）：
* **不能在 `Destroy()` 里复位** —— 窗口关闭期间它被**每帧**调用，复位等于没标记
* **不能靠"窗口实例变化"** —— 实测游戏**复用同一个窗口对象**（`window` 引用不变）

## 正确做法：靠"活跃度变化"检测重新开窗
```csharp
bool nowActive = SafeActive(window);
if (nowActive && !_wasActive) _userClosed = false;   // 不活跃 -> 活跃 = 重新打开
_wasActive = nowActive;
if (_userClosed) return;
```
原理：窗口关闭时 `Apply` 不被调用（`Render` 也就不跑），
所以下次被调用时若从"不活跃"变"活跃"，就代表**重新打开了**。

## 教训（写进代码注释）
**"每帧被调用"的方法里不能放"每帧复位"的状态** ——
`Destroy()` 在窗口关闭期间每帧执行，任何写在那里的复位都会立刻失效。
状态的复位必须绑定到**明确的事件**（这里是"窗口从关到开"这个边沿）。

## 待验证
重启游戏后打开 3×3 高炉，面板应恢复正常显示（含右上角 ✕ 关闭按钮）。
