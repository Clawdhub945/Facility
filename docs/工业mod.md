# 工业 mod 内容说明

> 这是本 mod 从「测试建筑」走向「工业 mod」的第一批正式内容。
> 技术前提全部经过对照实验验证，见 `docs/开发交接.md` 与本文末的「结论依据」。

## 一、新增内容一览

| 类型 | id | 名称 | 说明 |
|---|---|---|---|
| 物品 | **603010** | **钢** | `type 6 / sub 603`（金属类，与铁锭同段） |
| 物品 | **403010** | **钢制工具** | `type 4 / sub 403`（工具类），效率加成 **4.0**（普通 2.0 / 优质 3.0） |
| 建筑 | **105053** | **高炉** | 原生熔炉骨架 `furnace`（2×2）+ `FacilityFurnace` + `window_furnace` |

### 配方

| 生产设施 | 配方 | 工期 |
|---|---|---|
| **高炉**(105053) | **铁锭 ×2 → 钢 ×1** | 2 天 |
| **制造台**(105010，原版) | **原木 ×10 + 钢 ×3 → 钢制工具 ×1** | 10 天 |

### 燃料

高炉烧**煤**（`601001`）。煤的 `remark` 就是「燃料系数」、`effect_value=5.0`
（对比：柴火 1.0），在窗口的「**设置燃料类型**」里选。

## 二、关键实现要点

### 2.1 建筑骨架必须与 `class_name` 匹配（对照实验结论）

| | 105051 三乘三高炉（借 `trading_desk`） | 105052 熔炉对照（`furnace`） |
|---|---|---|
| 占地 | 3×3 | 2×2 |
| 窗口显示 | ✅ | ✅ |
| **配方下拉** | ❌ 空 | ✅ 有 |
| **燃料设置按钮** | ❌ 不可交互 | ✅ 可用 |

**原因**：`window_furnace` 的控件依赖 **prefab 上的 `FacilityFurnace` 组件**
（`furnace` 预制体自带；`trading_desk` 自带 `FacilityTradingDesk`），
`build.json` 的 `class_name` **改不了它**。

> **所以高炉必须用原生熔炉骨架（2×2）。** 想要 3×3 就得自己实现燃料/计划逻辑。

### 2.2 新建筑的配方必须显式克隆

配方 UI 读 `D.Ins.blueprint_list_dic_by_facility[facility_id]` ——
新建筑**不会**自动继承原生建筑的配方。用 `make_defs.py` 的
`clone_facility_blueprints()` 把原生熔炉的全套配方克隆一份给我们的 id。

### 2.3 新物品行要照抄同类型原生物品

物品行的字段很多（`price`/`weight`/`effect_value`/`remark`/`stuff_type`/
`stuff_sub_type`/`can_carry_one_by_one_anytime`/`incineration_result`…），
少一个都可能在 UI 或搬运逻辑里出问题。所以 `make_defs.py` 里用
`item_row(模板id, …)`：
* 钢 ← 模板 **铁锭 603001**
* 钢制工具 ← 模板 **普通工具 403001**（改 `effect_value` / `price`）

### 2.4 图标

`_tools/make_industry_icons.py` 生成（32×32，游戏一格 = 32 像素）：

| 文件 | 用途 |
|---|---|
| `ui_603010.png` / `603010.png` | 钢的 UI 图标 / 世界小图 |
| `ui_403010.png` / `403010.png` | 钢制工具的 UI 图标 / 世界小图 |
| `ui_105053.png` | 高炉的建造菜单图标（红砖炉体 + 烟囱 + 炉口火光） |

物品的世界模型统一用通用 prefab **`stuff_on_map`**（原生物品也这样），
所以**不需要自己做世界模型**，只要有图标 sprite。

## 三、已知风险

| 风险 | 说明 |
|---|---|
| **改原版制造台的配方表** | 「钢制工具」配方写在 `facility_id=105010` 上 —— 这是**改原版建筑的表**，若别的 mod 也写同一张表，谁生效取决于加载合并策略。（用户已确认接受） |
| **联机** | 加原版配方后，联机时客户端也要装本 mod，否则配方对不上 |
| **高炉尺寸** | 受骨架限制只能 **2×2**；要 3×3 需自研燃料/计划逻辑 |
| **图标 sprite 注册** | 图标 sprite 名（`ui_603010` 等）依赖游戏加载 `Defs/Textures` 下的图；若物品格显示白块，说明该 sprite 没进贴图表（需另想注册方式，参见 `CustomSprite.RegisterIcon`） |

## 四、加一座新工业建筑的步骤（框架化后）

1. `_tools/make_defs.py` 加常量（id/名称/骨架/类/窗口/配方）
2. 加 `stuff` / `build` / `tech` / `career` 行（照抄同类原生建筑）
3. 加 `blueprint` 行（配方）
4. `BuildingSpec.cs` 加一条规格（决定是否参与每日产出、是否改窗口）
5. `python _tools/make_defs.py --deploy` + **重启游戏**（镜像只在启动时刷新）

⚠ **不要手改 `C:\TerritoryModTest\Defs\*.json`** —— 下次 `--deploy` 会覆盖。
